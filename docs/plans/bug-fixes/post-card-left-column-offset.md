# 不具合対応方針: 左列の投稿カードの中身が左に寄る

## 1. 問題の整理

### 現象
ホーム画面(`app/page.tsx`)の投稿一覧で、**左の列**の投稿カードだけ中身が左側に寄って見える。

### 期待結果(中央列・右列と同じ状態)
- テストユーザー名の中心が、投稿カードの中心と一致する
- 投稿本文の表示範囲の左右の幅(余白)が同じになる
- 編集・削除ボタンの間の中心が、投稿カードの中心と一致する

### 前提・不明点
- 発生条件は3列表示時に確認できる想定。2列・1列表示での見え方は未確認。
- 直近コミット `9720a8b`「スクロールバー位置調整」が狙ったスクロールバーの**具体的な目標位置は、コミットからは読み取れず仕様不明**。

## 2. 原因分析

### カード自体には原因がない
`components/PostCard.tsx` と `app/globals.css` の `.post-card*` は、いずれも `width: 100%` と中央揃え(`justify-content` / `align-items: center`)で左右対称に作られている。中央列・右列が正常に表示されることからも、カードのCSSは原因ではない。

### 原因(特定済み)
コミット `9720a8b` で `app/globals.css` に追加された次の2行が原因。

```css
.post-grid-scroll {
  position: relative;
  left: 20px;      /* 追加 */
  overflow-y: auto;
}

.post-grid {
  position: relative;
  left: -20px;     /* 追加 */
}
```

1. 外側のスクロールコンテナを右へ +20px、内側のグリッドを左へ -20px ずらしている。グリッドの**見た目の位置は元に戻る**が、`overflow` による**クリッピング境界は外側コンテナの位置(+20px 側)に残る**。
2. `overflow-y: auto` を指定すると `overflow-x` も `auto` 扱いになるため、コンテナ左端より左にはみ出したグリッドの左 20px が切り取られる。
3. 切り取られるのは左列のカードの左端 20px だけ。見えているカードの中心と本来のカード中心がずれ、中身が左に寄って見える。右列は右側に余裕があるため欠けない。

### 副次的な事項
`.post-grid` の `width: 100%` はスクロールバー幅を除いた領域が基準になる。このため、`left` によるずらしでスクロールバーの位置を調整しようとすると、上記のクリップが起きやすい。

## 3. 対応方針

### 方針
`left` による位置ずらしをやめ、**外側のコンテナを横幅いっぱいにして、左右の padding でグリッドを中央に置く**。スクロールバーは画面端側に表示される。

### 案の比較

| 案 | 内容 | 評価 |
|---|---|---|
| **A(推奨)** | `left` 2行を削除。`.post-grid-scroll` を `width: 100%` にし、`padding-inline` でグリッドを最大 1200px・中央配置にする | クリップの原因を取り除ける。CSSのみの最小変更 |
| B | `left` 2行を削除するだけ | 最小変更だが、スクロールバーが `9720a8b` 以前の位置(カード列の近く)に戻る |
| C | `.post-grid` に `padding-left: 20px` などを足して補正 | クリップを隠すだけで、ずれの原因が残る。非推奨 |

### 既存設計への影響
- `PostCard.tsx`、`.post-card*` のCSS、`app/page.tsx` は変更しない。
- 変更は `app/globals.css` の2セレクタに限定する。

## 4. 具体的な実装方法(案A)

変更対象は `app/globals.css` のみ。

1. `.post-grid-scroll`
   - `left: 20px;` を削除する。
   - `width: min(100% - 40px, 1200px);` と `margin: 0 auto;` を次に置き換える。
     ```css
     width: 100%;
     box-sizing: border-box;
     padding-inline: max(20px, calc((100% - 1200px) / 2));
     ```
   - `position: relative;` は他で使っていなければ削除してよい。実装時に確認する。
2. `.post-grid`
   - `left: -20px;` を削除する。
   - `position: relative;` も削除する(他に依存する箇所がないことを実装時に確認する)。
3. `@media` 内の `.post-grid` 定義(列数と gap のみ)は変更しない。

### 注意点
- `padding-inline` の `%` は、包含ブロックの幅を基準に計算される。実装後、1200px 超の幅でグリッドが中央に収まることを確認する。
- スクロールバーの目標位置に希望がある場合(例: カードの右端から何px)は、実装前に確認する。

## 5. 変更が想定されるファイル

| ファイル | 内容 |
|---|---|
| `app/globals.css` | `.post-grid-scroll`、`.post-grid` の修正 |

参考確認のみ(変更しない): `components/PostCard.tsx`、`app/page.tsx`、`app/layout.tsx`

`.post-grid` を使っているのは `app/page.tsx` のみのはずだが、実装時に `app/profile/*` などで使われていないかを再確認する。
